# anti-slop provenance

The files in this directory are vendored from
[`dmmulroy/anti-slop`](https://github.com/dmmulroy/anti-slop) at commit
[`6d538555cb151d4121ed51a27db81890eacf8ae9`](https://github.com/dmmulroy/anti-slop/commit/6d538555cb151d4121ed51a27db81890eacf8ae9).

Vendored scope:

- `src/index.ts`
- all generic production rules in `src/rules/`
- production helpers in `src/shared/`
- the upstream MIT `LICENSE`

Upstream tests, skills, scripts, and the Effect-specific plugin are deliberately
not vendored. The checked-in anti-slop canary covers the five rules enabled by
this repository.
